# 网易云音乐 · MyGo

用 Go 和 [MyGo](https://github.com/egoist/mygo) 写的第三方网易云音乐桌面客户端，原生界面，无 WebView。

## 功能

- 扫码登录，登录态保存在系统凭据存储中
- 每日推荐、推荐歌单、排行榜、我的歌单
- 搜索单曲、歌手、专辑、用户与播客，输入时显示搜索建议，保留搜索历史
- 歌手页的热门与最新歌曲、专辑与动态，关注歌手；专辑页与用户页
- 播客：浏览与收听节目，订阅播客；在本机把节目转写成字幕（Qwen3-ASR），像歌词一样随播放滚动
- 私人 FM（推荐 / 熟悉 / 探索）与心动模式
- 边下边播，支持标准 / 较高 / 极高 / 无损（FLAC）/ Hi-Res 音质
- 听过的歌曲缓存在本机，再次播放无需等待；支持自定义歌曲缓存目录，并在下次启动时迁移已有缓存
- 音量均衡，暂停与继续时淡出淡入，拖动进度无杂音
- 退出后再打开，从上次的播放队列与进度继续
- 逐字歌词与翻译，正在播放页的「律动」视图与歌曲评论
- 刘海播放器：在屏幕顶部刘海处显示迷你播放器，悬停展开（在设置中开启）
- 喜欢歌曲、播放队列、随机与循环播放
- 浅色 / 深色 / 跟随系统

## 构建

需要 Go 1.27+。

```bash
go tool mygo dev     # 开发模式运行
go tool mygo build   # 打包到 build/
go test ./...        # 运行测试
```

## 歌曲缓存目录

在设置的「缓存」区域选择空文件夹，可更改歌曲缓存目录，也可恢复系统默认目录。更改时可选择迁移已有歌曲缓存或仅切换目录，均在下次启动时执行；重启前可以取消更改。

迁移支持跨磁盘，仅搬迁完整的歌曲缓存及其元数据。新路径保存成功后才清理旧文件；复制或保存失败仍使用原目录。不迁移时旧缓存会保留。目标目录已有文件时不会合并或覆盖，请先选择空目录。迁移期间请勿运行另一个应用实例。

若迁移过程中应用被强制结束，旧缓存不会提前删除，但可能留下暂存目录或已复制的新目录。再次启动若提示目标目录非空，可在设置中取消更改或另选空目录；确认原缓存仍在后，再自行清理本次复制的文件。
